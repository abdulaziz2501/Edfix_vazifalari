##  Qanday foydalanish mumkin

### 1) Repository’ni klon qilish:
```bash
git clone https://github.com/abdulaziz2501/Edfix_vazifalari.git
cd Edfix_vazifalari
```

### 2) Virtual muhit yaratish (tavsiya etiladi):
```bash
python -m venv .venv
# Linux/macOS
source .venv/bin/activate
# Windows
.venv\Scripts\activate
```

### 3) Zarur kutubxonalarni o‘rnatish:
Agar notebooklarda kerakli kutubxonalar `requirements.txt` ichida bo‘lsa:
```bash
pip install -r requirements.txt
```
Aks holda, mos kutubxonalarni (masalan: `numpy`, `pandas`, `matplotlib`, `scikit-learn`) qo‘lda o‘rnatishingiz mumkin.

### 4) Noteboklarni ishga tushirish:
```bash
jupyter notebook
```
Odatda `localhost:8888` ochiladi — u yerdan istalgan `.ipynb` faylini ochib, kodlarni bosqichma-bosqich bajarib ko‘rish mumkin.
